# Google Play listing (en-US)

| Field | File | Limit |
| --- | --- | --- |
| App name | `en-US/title.txt` | 30 |
| Short description | `en-US/short_description.txt` | 80 |
| Full description | `en-US/full_description.txt` | 4000 |

Play has no keyword field. It ranks on the app name, short description and full description, so target phrases appear there naturally, never stuffed.

## Keyword targets (researched Oct 6, 2026)

Competition = how many of Play's top 10 US results already have the phrase in their app name. Lower is easier to rank for. Google autocomplete returned suggestions for every phrase below, so all have search demand; exact monthly volumes need Semrush or Ahrefs.

## Policy guardrails

- No ratings, rankings, testimonials or "#1/best" claims in any listing text.
- Contract and expense tools carry "not legal, tax or accounting advice".
- Every feature named here must exist in the shipped build.
